**Quelldatei im Repository:**

## Enthalten

- responsives Layout für Smartphone, Tablet und Desktop
- prominenter Termin-CTA
- interaktive Termin-Anfrage
- klickbare Telefon- und Routenfunktionen
- Premium-Intro / Mirror-Reveal
- optimierte und nachgeschärfte Salonbilder
- mobile Navigation und feste Termin-Leiste
- Google Maps / Apple Karten-Verlinkung
- reduzierte Animationen bei `prefers-reduced-motion`

## Geräte

Die Vorschau ist für moderne Browser auf **Windows, macOS, iPhone/iPad und Android/Samsung** ausgelegt.
